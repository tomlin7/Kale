# tools/pkg — Package Manager & Build Tool (kale-pm)

## Version
`0.1.0`

## Description
Monorepo and ecosystem package manager for Kale. Handles semantic version resolution, TOML manifest parsing, hermetic builds, and artifact caching.

## Status
🟡 In Progress

## Dependencies
- `packages/std`: toml/text, collections, fs
- `vcs`: git repository discovery and hash verification
