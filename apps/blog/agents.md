# Blog Platform

## Version
`0.0.1`

## Description
Blog and publishing platform built on libs/web and libs/sql.

## Status
Current status: 🔴 Not Started

## Dependencies
- libs/web
- libs/sql
- packages/std

## Build Instructions
`kale build apps/blog/main.kl -o bin/kale_blog.exe`

## Coding Conventions
- MVC and route-handler design pattern
- PascalCase for data models and route controllers, snake_case for functions

## Short-term Milestones
- [ ] Markdown rendering
- [ ] Post CRUD
- [ ] SQLite storage
- [ ] HTML templates

## Future Plans
User authentication, RSS feeds, media uploads, themes.
