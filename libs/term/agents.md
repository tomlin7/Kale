# libs/term — Virtual Terminal Emulator & VT100 Engine

## Version
`0.1.0`

## Description
Complete terminal abstraction layer providing ANSI/VT100/VT220 escape code parsing, 24-bit TrueColor support, ConPTY/pty spawning, and 2D cell grid buffers.

## Status
🟡 In Progress

## Dependencies
- `packages/std`: collections, text

## Build Instructions
```bash
kale build tests/test_term.kl -o bin/test_term.exe
```
